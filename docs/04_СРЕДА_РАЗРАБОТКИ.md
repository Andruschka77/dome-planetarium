# СРЕДА РАЗРАБОТКИ И СИСТЕМА КОНТРОЛЯ ВЕРСИЙ

## Среда разработки

В качестве базовой интегрированной среды разработки утверждена IntelliJ IDEA (компания JetBrains, версия 2025.3+). Данная IDE распространяется в рамках единого дистрибутива с бесплатным базовым функционалом. Выбор обусловлен возможностью одновременного ведения проекта на двух языках: поддержка Java реализована нативно, а поддержка Python обеспечивается установкой официального плагина. Среда включает встроенный Git-клиент, инструменты рефакторинга и графический отладчик. Альтернативные варианты (Visual Studio Code и PyCharm) были отклонены из-за недостаточного удобства работы с Java в первом случае и отсутствия поддержки Java во втором.

## Языки программирования

Процедурная часть алгоритмов реализуется на языке Python версии 3.12. Данный язык обеспечивает лаконичность записи математических вычислений, связанных с преобразованием сферических координат и расчетом сеток деформации, а стандартная библиотека предоставляет готовые структуры данных: списки, словари, кортежи и очереди [4; 14]. Версия 3.12 выбрана благодаря стабильности и полной поддержке в инструментарии разработки.

Объектно-ориентированное ядро управления строится на платформе Java 21 LTS (сборка Eclipse Temurin). Версия с длительным циклом поддержки предоставляет современные языковые средства: неизменяемые записи (records), запечатанные интерфейсы (sealed interfaces) и сопоставление с образцом (pattern matching) [15]. Эти возможности оптимально подходят для моделирования компонентов проекционного комплекса (проекторы, калибровочные профили, медиапотоки, сеансы) и обработки конечных автоматов воспроизведения.

Корректность настройки инструментальной среды подтверждена тестовыми программами python/hello.py и java/src/Hello.java из репозитория, выводящими информацию о версиях интерпретатора и JVM.

## Система управления базами данных

Для хранения параметров оборудования, калибровочных сеток, списков воспроизведения и телеметрии выбрана реляционная СУБД PostgreSQL 18. Предметная область купольного планетария эффективно укладывается в реляционную парадигму: залы агрегируют проекторы, проекторы связаны с профилями юстировки, а сеансы регистрируют параметры показа. PostgreSQL обеспечивает строгую транзакционность, контроль целостности внешних ключей и предоставляет тип JSONB для хранения неструктурированных матриц геометрической коррекции (warping mesh) [10]. Поддержка драйверов для Python и Java позволяет обеим частям программного комплекса взаимодействовать с общим хранилищем.

## Система контроля версий

Для версионирования исходного кода применяется распределенная система Git версии 2.50.1. Локальные копии хранят целостную историю разработки, а встроенный в IntelliJ IDEA клиент упрощает операции фиксации изменений. Удаленный репозиторий dome-planetarium развернут на платформе GitHub, обеспечивая проверяющему преподавателю доступ к исходным материалам по прямой ссылке.

Структура репозитория содержит файл описания README.md, конфигурацию игнорирования служебных файлов .gitignore, каталоги с разделами отчёта docs, процедурным кодом python, классами java и базой данных db. Сообщения коммитов формируются на русском языке в строгом соответствии с характером внесенных правок (например, «Добавлен список источников»).
