## Описание проекта
Проект посвящён исследованию архитектуры и разработке программных средств управления купольными проекционными комплексами цифрового планетария (Fulldome).
Разрабатываемое программное обеспечение решает задачи:
* автоматизированной предсеансовой проверки и валидации параметров сферического медиаконтента (Dome Master / Fisheye, разрешение до 8K, кадровая частота, многоканальный звук);
* координации оптико-геометрической калибровки многопроекторного кластера (алгоритмы нелинейной геометрической деформации — *warping* и бесшовного сведения зон перекрытия — *edge blending*);
* диспетчеризации сценария показа и синхронизации воспроизведения аудиовизуальных дорожек;
* централизованного сбора телеметрии оборудования (FPS, температура лазерных источников, пропуски кадров) и протоколирования хода сеансов.
