## Описание проекта

Проект посвящён исследованию архитектуры и разработке программных средств управления купольными проекционными комплексами цифрового планетария (Fulldome).

Разрабатываемое программное обеспечение решает комплекс задач:
* **Предсеансовая валидация контента:** автоматизированная проверка целостности и параметров сферических медиапакетов (формат Dome Master / Fisheye до 8K, кадровая частота, многоканальное пространственное аудио 7.1, сверка контрольных сумм MD5);
* **Оптико-геометрическая юстировка кластера:** координация процессов бесшовного сведения многопроекторного купольного кластера (алгоритмы геометрической деформации — *warping* и расчета ширины масок краевого перекрытия — *edge blending* с поддержкой сменных алгоритмических стратегий);
* **Диспетчеризация сеанса:** координация сценария показа и управление воспроизведением аудиовизуальных потоков;
* **Сбор и анализ телеметрии:** протоколирование работы лазерных источников света (температурный режим $<70^\circ\text{C}$), контроль кадровой синхронизации медиасерверов (джиттер, пропуски кадров) и формирование интегрального индекса стабильности сеанса (FSI).

## Этапы выполнения практики

### Контрольная точка №1: Теоретический этап
* Анализ предметной области оптико-геометрического сведения и управления купольными проекциями.
* Обзор современных научных отечественных и зарубежных источников (ВАК, IEEE, Scopus).
* Выполнен академический перевод профильной научной публикации по калибровке многопроекторных дисплеев.
* *Подробные материалы:* [`docs/01_ВВЕДЕНИЕ.md`](docs/01_ВВЕДЕНИЕ.md), [`docs/02_ПРЕДМЕТНАЯ_ОБЛАСТЬ.md`](docs/02_ПРЕДМЕТНАЯ_ОБЛАСТЬ.md), [`docs/07_ИСТОЧНИКИ.md`](docs/07_ИСТОЧНИКИ.md), [`docs/08_ПЕРЕВОД_СТАТЬИ.md`](docs/08_ПЕРЕВОД_СТАТЬИ.md).

### Контрольная точка №2: Процедурное моделирование и реализация (Python)
* Спроектирована сквозная модель бизнес-процесса в нотации **BPMN 2.0** (`models/bpmn.bpmn`).
* Разработана нормализованная логическая схема реляционной базы данных в **3НФ** (`models/er_logical.drawio`).
* Реализована процедурная программа на **Python 3.12** (4 алгоритма: верификация сведения кластера $O(N \cdot M)$, анализ телеметрии $O(K)$, валидация медиапакета и аудит проекторов).
* *Подробная документация и примеры запуска:* [**`python/README.md`**](python/README.md).

### Контрольная точка №3: Объектно-ориентированная архитектура (Java 21)
* Построена каноническая **UML-диаграмма классов** (`models/classes.drawio` / `models/classes.png`).
* Спроектировано и реализовано ядро системы на языке **Java 21 (LTS)** с применением библиотеки **Project Lombok**:
  * 15 классов и интерфейсов, декомпозированных по пакетам `model` и `service`;
  * Реализация фундаментальных принципов ООП: строгая инкапсуляция полей, наследование в иерархии `Employee` (`Operator`, `Engineer`, `ContentManager`), полиморфная диспетчеризация обязанностей `performDuty()`;
  * Применение шаблона проектирования **«Стратегия» (Strategy)** для взаимозаменяемых правил расчёта маски сшивки (`CalibrationRule` $\to$ `StandardBlendRuleImpl`, `StrictBlendRuleImpl`);
* Проведён организационный этап: сформирован состав команды проекта, выполнен анализ 10 актуальных вакансий рынка труда и образовательных программ.
* *Подробная документация и примеры запуска:* [**`java/src/README.md`**](java/src/README.md).

## Быстрый запуск

### 1. Процедурная программа (Python)
```bash
# Не требует сторонних библиотек
python python/main.py
```

### 2. Объектно-ориентированная программа (Java 21)
```bash
cd java/src
# Сборка проекта
mvn clean compile
# Запуск через Maven
mvn exec:java -Dexec.mainClass="Main"
# Либо прямой запуск скомпилированных классов
java -cp target/classes Main
```
